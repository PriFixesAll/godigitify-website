# GoDigitify Website

A premium AI-powered corporate website for GoDigitify, focused on software engineering, digital transformation, branding, and intelligent business solutions.

---

## Tech Stack

- Next.js 15
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

---

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
