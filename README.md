# GoDigitify Website

A modern, responsive, and scalable corporate website for GoDigitify, showcasing software development, AI solutions, and digital transformation services.

---

## Project Overview

The GoDigitify Website is designed to establish a strong online presence for the company by presenting its services, expertise, technologies, and contact information through a clean, modern, and high-performance user interface.

The project follows industry-standard development practices with a focus on maintainability, scalability, responsiveness, security, and performance.

## Installation

Clone the repository

```bash
git clone https://github.com/USERNAME/godigitify-website.git
```

Navigate into the project

```bash
cd godigitify-website
```

Install frontend dependencies

```bash
cd frontend
npm install
```

Install backend dependencies

```bash
cd ../backend
npm install
```

---

## Running the Project

### Frontend

```bash
cd frontend
npm run dev
```

### Backend

```bash
cd backend
npm run dev
```

---

## Environment Variables

Create a `.env` file inside the backend folder.

Example:

```env
PORT=

MONGODB_URI=

JWT_SECRET=

EMAIL_USER=

EMAIL_PASSWORD=
```
